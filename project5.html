Overview

Project Overview

This project demonstrates a real-world AWS networking setup using a custom VPC with isolated public and private subnets.

A bastion host enables secure SSH access to private instances, while a NAT Gateway allows outbound internet access without exposing internal resources.

Key Features

What Was Implemented

  • Custom VPC with CIDR configuration
  • Public & private subnet architecture
  • Bastion host for secure SSH access
  • Private EC2 without public IP
  • Internet Gateway for public connectivity
  • NAT Gateway for secure outbound access
  • Route tables for traffic control
  • Security groups for access restriction
