Project 09 · AWS Security & CDN

Secure File Sharing
with S3 and CloudFront

A secure cloud-based file-sharing solution built using Amazon S3, Amazon CloudFront, IAM, and Lambda@Edge. The project enables protected file storage, secure content delivery through signed URLs, request validation at edge locations, and controlled access management using AWS security best practices.

Overview

Project Overview

The Secure File Sharing System was developed to provide a secure and efficient method for sharing files stored in Amazon S3 while preventing unauthorized public access.

Files uploaded to Amazon S3 are distributed globally through Amazon CloudFront, which uses signed URLs to provide temporary and controlled access to resources. Public access to the S3 bucket is completely restricted, ensuring that files can only be accessed through authorized CloudFront requests.

AWS Lambda@Edge is integrated to validate incoming requests at CloudFront edge locations by checking conditions such as custom request headers before allowing access. IAM policies and roles are configured to ensure secure communication between AWS services and to maintain strict access control.

Scope

Project Scope

The scope of this project is to design and implement a secure file-sharing system that protects files from unauthorized access while enabling efficient global delivery using Amazon CloudFront CDN services.

  • Store uploaded files securely inside Amazon S3 buckets
  • Block all direct public access to S3 resources
  • Generate time-limited signed URLs for secure file access
  • Deliver content globally using Amazon CloudFront CDN
  • Implement IAM policies for secure service-level access control
  • Use Lambda@Edge to validate requests before granting access
  • Improve content delivery performance and security simultaneously

Key Features

What Was Implemented

  • Secure file storage using Amazon S3 with blocked public access
  • Amazon CloudFront distribution for low-latency global content delivery
  • Signed URL implementation for temporary and controlled file access
  • Lambda@Edge integration for request validation and additional security
  • IAM roles and policies for secure AWS resource permissions
  • Access control mechanisms to prevent unauthorized file downloads
  • Scalable and secure serverless file-sharing architecture
