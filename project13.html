Overview

Project Overview

The Scalable Web Application with Load Balancing project was developed to demonstrate a highly available and scalable cloud-native web hosting architecture using AWS services.

The application is hosted on multiple EC2 instances configured with Apache and PHP. Incoming user traffic is distributed across instances using an Application Load Balancer (ALB), while Auto Scaling automatically launches or replaces EC2 instances based on traffic demand and health checks.

Amazon RDS MySQL is used as the backend relational database service, and Amazon S3 is integrated for storing static assets such as images and media files. The infrastructure is deployed inside a custom VPC using multiple subnets, launch templates, security groups, and automated user data scripts.

Instead of purchasing a custom domain, the project uses the free ALB DNS endpoint for accessing the web application and avoiding additional Route 53 domain registration costs.

Scope

Project Scope

The scope of this project is to design and implement a scalable and fault-tolerant web application architecture using AWS cloud-native services.

  • Deploy scalable PHP web applications on EC2 instances
  • Distribute traffic using Application Load Balancer (ALB)
  • Automatically scale EC2 instances using Auto Scaling Groups
  • Integrate Amazon RDS MySQL for backend database management
  • Store and serve static assets using Amazon S3
  • Automate EC2 configuration using Launch Templates and User Data scripts
  • Implement high availability using multiple Availability Zones
  • Replace unhealthy instances automatically using Auto Scaling health checks

Key Features

What Was Implemented

  • Custom VPC with public subnets across multiple Availability Zones
  • Application Load Balancer for intelligent traffic distribution
  • Auto Scaling Group for automatic EC2 scaling and recovery
  • EC2 Launch Templates with automated Apache and PHP setup
  • Amazon RDS MySQL database integration for centralized storage
  • Amazon S3 integration for static file hosting and storage
  • Security Groups configured for secure communication between services
  • Fault-tolerant and highly available cloud infrastructure design
