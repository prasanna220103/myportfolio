Overview

Project Overview

The Hybrid Cloud Setup Using VPN project was developed to demonstrate secure communication between a simulated on-premises environment and AWS Cloud infrastructure using enterprise hybrid networking concepts.

The project uses AWS Site-to-Site VPN to establish encrypted communication between a locally hosted Ubuntu Server virtual machine running inside VirtualBox and AWS resources deployed within an Amazon VPC.

Amazon EC2 instances were launched inside the VPC to act as cloud-side resources, while route tables, subnets, and networking components were configured to enable secure bidirectional communication between local and cloud environments.

The implementation demonstrates practical hybrid cloud architecture concepts including VPN connectivity, secure routing, VPC networking, and integration between on-premises infrastructure and AWS Cloud services.

Scope

Project Scope

The scope of this project is to design and implement a secure hybrid cloud architecture by connecting a simulated on-premises environment with AWS Cloud infrastructure using AWS Site-to-Site VPN.

  • Create a simulated on-premises environment using VirtualBox and Ubuntu Server
  • Configure Amazon VPC, subnets, and Internet Gateway for AWS networking
  • Deploy Amazon EC2 instances inside AWS VPC
  • Establish secure Site-to-Site VPN connectivity between local and AWS environments
  • Configure route tables for hybrid cloud communication
  • Enable encrypted communication using VPN tunnels
  • Implement secure hybrid networking architecture
  • Demonstrate connectivity between on-premises and cloud resources
