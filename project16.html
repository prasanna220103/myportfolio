Overview

Project Overview

The Multi-Region Disaster Recovery Plan project was developed to demonstrate high availability and business continuity architecture using AWS cloud services deployed across multiple geographic regions.

The project deploys application servers and database infrastructure across two AWS regions, with Mumbai configured as the primary region and Singapore configured as the disaster recovery region.

Amazon Route 53 health checks continuously monitor the health of the primary application environment and automatically redirect user traffic to the disaster recovery environment during failures or outages.

AWS CloudFormation is used to automate infrastructure provisioning and management, enabling consistent deployment of resources across regions while reducing manual configuration effort.

Scope

Project Scope

The scope of this project is to design and implement a disaster recovery architecture that ensures application availability even during regional outages or infrastructure failures.

  • Deploy application infrastructure across Mumbai and Singapore regions
  • Configure disaster recovery architecture using secondary cloud resources
  • Implement automated failover using Route 53 health checks
  • Redirect user traffic during primary region failures
  • Automate infrastructure deployment using AWS CloudFormation
  • Configure cross-region application and database setup
  • Ensure high availability and business continuity planning
  • Minimize application downtime during failures
