Project 14 · AWS Real-Time Chat Application

Real-Time Chat Application
with AWS AppSync and DynamoDB

A cloud-based real-time chat application built using AWS AppSync, Amazon DynamoDB, Amazon Cognito, and Amazon S3. The project demonstrates GraphQL-based communication, secure user authentication, real-time messaging, cloud storage integration, and scalable serverless application architecture using AWS services.

Overview

Project Overview

The Real-Time Chat Application project was developed to demonstrate a scalable cloud-native messaging system using AWS managed services and serverless architecture.

The application enables users to communicate in real time using AWS AppSync GraphQL APIs for instant message delivery and synchronization between connected users.

Amazon DynamoDB is used to securely store chat messages and conversation data, while Amazon Cognito manages user authentication, signup, and login functionality for secure access control.

Amazon S3 is integrated for uploading and storing files, images, and media shared inside the chat application. The frontend application is hosted using Amazon S3 Static Website Hosting to provide a lightweight and scalable deployment solution.

Scope

Project Scope

The scope of this project is to design and implement a fully functional cloud-based real-time chat application using AWS serverless and managed services.

  • Implement real-time messaging using AWS AppSync GraphQL APIs
  • Store and manage chat messages using Amazon DynamoDB
  • Provide secure user authentication using Amazon Cognito
  • Enable users to upload files and media using Amazon S3
  • Host the frontend application using Amazon S3 Static Website Hosting
  • Integrate GraphQL queries, mutations, and subscriptions
  • Build a scalable and serverless cloud application architecture
  • Enable secure communication between frontend and backend services
