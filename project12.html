Infrastructure as Code (IaC)
using Terraform for AWS 3-Tier Architecture

A complete AWS 3-tier architecture deployed using Terraform as an Infrastructure as Code (IaC) solution. The project automates provisioning of AWS networking, compute, database, storage, and security resources including VPC, EC2, RDS, S3, and IAM to build a scalable, reusable, and secure cloud infrastructure environment.

Overview

Project Overview

The Infrastructure as Code (IaC) AWS 3-Tier Architecture project was developed to automate the deployment and management of a secure and scalable cloud infrastructure using Terraform.

The architecture follows a standard 3-tier design model consisting of presentation, application, and database layers. Terraform scripts are used to provision AWS resources including VPC networking, EC2 web servers, Amazon RDS database instances, Amazon S3 storage, IAM roles, security groups, and routing configurations.

This project demonstrates how Infrastructure as Code principles improve automation, scalability, consistency, and operational efficiency while reducing manual cloud infrastructure management tasks.

Scope

Project Scope

The scope of this project is to design and implement a complete AWS 3-tier architecture using Terraform as the Infrastructure as Code automation tool.

  • Create a custom VPC with public and private subnets
  • Configure route tables, internet gateways, and networking components
  • Deploy EC2 web servers with Apache and custom HTML applications
  • Provision Amazon RDS MySQL database instances in private subnets
  • Integrate Amazon S3 for scalable object storage
  • Configure IAM roles, policies, and security groups
  • Automate infrastructure deployment using reusable Terraform scripts

Key Features

What Was Implemented

  • Custom AWS VPC creation with segmented networking architecture
  • Public and private subnet configuration for secure resource isolation
  • EC2 Ubuntu web server deployment with Apache configuration
  • Amazon RDS MySQL database setup for backend storage
