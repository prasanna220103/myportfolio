Overview

Project Overview

The Cloud Infrastructure Automation using Terraform and AWS project was developed to demonstrate automated cloud infrastructure deployment using Infrastructure as Code (IaC) principles.

Terraform configuration files are used to provision and manage AWS services including Amazon VPC, public and private subnets, EC2 instances, Application Load Balancer, and Amazon RDS database resources.

The project automates infrastructure deployment and reduces manual configuration effort while improving consistency, scalability, and repeatability across AWS environments.

The architecture includes a custom VPC with networking configuration, secure routing, web server deployment, load balancing, and backend database integration for a complete cloud-native infrastructure setup.

Scope

Project Scope

The scope of this project is to design and implement a fully automated AWS cloud infrastructure deployment using Terraform and Infrastructure as Code concepts.

  • Automate AWS infrastructure provisioning using Terraform
  • Create a custom VPC with public and private subnets
  • Deploy Amazon EC2 web server instances
  • Configure Application Load Balancer for traffic distribution
  • Deploy Amazon RDS MySQL database infrastructure
  • Configure route tables and networking components
  • Implement Security Group configuration for secure communication
  • Manage infrastructure using Infrastructure as Code practices
