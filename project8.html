Project 08 · AWS Data Engineering

Data Lake Implementation
using AWS Glue and Athena

A serverless data lake solution built using Amazon S3, AWS Glue, and Amazon Athena for storing, cataloging, and querying structured data efficiently. The project enables automated schema discovery, centralized metadata management, secure access control, and SQL-based analytics without managing infrastructure.

Overview

Project Overview

The Data Lake Implementation project was developed to demonstrate how AWS managed services can be used to build a scalable and serverless data lake architecture for storing and analyzing structured data.

Raw CSV data files are stored inside Amazon S3 buckets and automatically scanned using AWS Glue crawlers. The crawler identifies the data schema and creates metadata tables inside the AWS Glue Data Catalog. Amazon Athena is then used to perform SQL queries directly on the data stored in S3 without provisioning or managing servers.

IAM policies and roles are configured to provide secure and controlled access to AWS Glue and Athena resources while maintaining operational security and governance.

Scope

Project Scope

The scope of this project is to design and implement a basic serverless data lake architecture using AWS managed services for data storage, cataloging, and analytics.

  • Store structured CSV data files in Amazon S3 buckets
  • Automatically discover schemas using AWS Glue crawlers
  • Create metadata tables using AWS Glue Data Catalog
  • Perform serverless SQL-based querying using Amazon Athena
  • Implement secure IAM access policies for AWS resources
  • Enable scalable and cost-efficient data analytics workflows
