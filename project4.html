Overview

Project Overview

Phishing attacks are one of the most common cybersecurity threats. This project builds an intelligent detection system using machine learning to classify URLs as phishing or legitimate.

It extracts features from SSL certificates, WHOIS data, HTTP headers, and webpage structure, and feeds them into trained ML models for real-time analysis.

Key Features

What Was Implemented

  • URL feature extraction (domain age, length, special characters)
  • SSL certificate validation
  • WHOIS domain analysis
  • HTTP header inspection
  • Web scraping with BeautifulSoup
  • ML models (Random Forest, Logistic Regression)
  • Dataset training with cross-validation
  • CLI + basic web interface
