Project 10 · AWS Serverless

Serverless Web Application
using AWS Lambda and API Gateway

A fully serverless web application built using AWS managed services that enables authenticated users to securely upload files to Amazon S3. The project integrates Amazon Cognito for authentication, API Gateway for REST API management, AWS Lambda for backend processing, and DynamoDB for storing file metadata in a scalable and secure cloud-native architecture.

Overview

Project Overview

The Serverless File Upload Web Application was developed to provide a secure and scalable platform for authenticated users to upload and manage files through a browser-based web interface.

Amazon Cognito is used for secure user authentication and authorization, while Amazon API Gateway handles REST API requests from the frontend application. AWS Lambda functions process backend logic such as file uploads and metadata handling. Uploaded files are securely stored in Amazon S3, and file-related metadata is maintained in Amazon DynamoDB.

The project follows a fully serverless architecture, eliminating infrastructure management while providing scalability, high availability, and cost optimization using AWS managed services.

Scope

Project Scope

The scope of this project is to design and implement a fully serverless file upload web application using AWS cloud services for authentication, API management, storage, and backend processing.

  • User authentication and authorization using Amazon Cognito
  • REST API integration using Amazon API Gateway
  • Backend processing using AWS Lambda functions
  • Secure file uploads and storage using Amazon S3
  • Metadata storage using Amazon DynamoDB
  • Browser-based frontend interface using HTML, CSS, and JavaScript
  • Implementation of a scalable and fully serverless cloud architecture
