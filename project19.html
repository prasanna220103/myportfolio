Overview

Project Overview

The Real-Time Chat Application using WebSockets and Serverless Architecture project was developed to demonstrate secure and scalable instant messaging capabilities using AWS managed services.

The application uses Amazon API Gateway WebSocket APIs to establish persistent bidirectional communication between connected users and backend services. AWS Lambda functions process incoming connections, disconnections, and real-time chat messages.

Amazon DynamoDB stores active WebSocket connection IDs and chat-related state information, while Amazon Cognito handles secure user signup, login, authentication, and identity federation for authorized platform access.

The architecture is fully serverless and event-driven, enabling automatic scalability, low operational overhead, and efficient handling of multiple simultaneous user connections without server management.

Scope

Project Scope

The scope of this project is to design and implement a scalable real-time messaging platform using AWS serverless services and WebSocket APIs for persistent communication between authenticated users.

  • Enable bidirectional real-time communication using API Gateway WebSocket APIs
  • Implement secure user signup and login using Amazon Cognito
  • Store and manage active WebSocket connection IDs using DynamoDB
  • Broadcast real-time chat messages using AWS Lambda functions
  • Build a fully serverless architecture without server management
  • Handle scalable event-driven communication for multiple connected users
  • Manage user authentication and authorization securely
  • Provide scalable cloud-native messaging infrastructure
