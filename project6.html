Overview

Project Overview

This project implements an automated AWS cost monitoring system that tracks cloud expenses in real time and sends alerts when spending exceeds defined thresholds.

AWS Lambda retrieves billing data from Cost Explorer, compares it with budget limits, and triggers notifications via Amazon SES. EventBridge schedules execution for continuous monitoring.

Key Features

What Was Implemented

  • Automated cost tracking using AWS Cost Explorer API
  • Threshold-based alert system
  • Serverless automation with AWS Lambda
  • Scheduled execution using EventBridge
  • Email alerts via Amazon SES
  • Customizable budget monitoring logic
  • Reduced manual cost tracking effort
